# Security Policy

## Supported Versions
| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability
OBLIQ treats security and document privacy with high priority. Because `obliq-OCR` processes sensitive tax and financial compliance documents, any vulnerability relating to data leakage, temp file handling, or dependency exploits should be reported privately.

Please report vulnerabilities directly via GitHub Security Advisories or by reaching out to the maintainers internally. Do not open public issues for security vulnerabilities.
